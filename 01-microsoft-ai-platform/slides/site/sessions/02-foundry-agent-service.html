NAMING

From “AI Agent Service” to “Foundry Agent Service”

Same service, renamed by Microsoft as the platform became “Microsoft Foundry”.

It grew from “an API to create an assistant” into a managed runtime for production agents.

New since 2025:

hosted agents,

the Toolbox MCP endpoint,

Slide 17

DECISION

Prompt-based vs Hosted agents

Prompt-based agentHosted agent
DefinitionModel + instructions + tools, declared in the serviceYour own code / framework, deployed to a managed runtime
Best whenStandard orchestration, fast startCustom logic, webhooks, non-OpenAI protocols
FrameworksBuilt-in orchestrationAgent Framework, LangGraph, Semantic Kernel, custom
RuntimeManaged by FoundrySession-isolated, autoscaling, zero idle cost
DeployConfigure in portal / YAML / SDKDeploy with one command

Rule of thumb: start prompt-based; move to hosted when you need to bring your own code.

RUNTIME

Hosted agents — a runtime you don't have to run

Slide 18

RUNTIME

Hosted agents — a runtime you don't have to run

Session isolation

Each conversation runs isolated — no cross-tenant / cross-session leakage.

Autoscaling

Scales with load automatically; you don't manage servers or containers.

Zero idle cost

No traffic, no compute charge — pay for work, not for waiting.

One-command deploy

Ship code to the managed runtime; rollbacks & versioning handled.

Managed cross-cutting

Containerisation, web server, security, instrumentation — all built in.

Toolbox access

Reaches Code Interpreter, Web Search, AI Search, OpenAPI, MCP, A2A.

It removes the plumbing that normally sits between a working prototype and a production agent.

OPEN STANDARDS

MCP · A2A · OpenAPI — no protocol lock-in

Slide 20

OPEN STANDARDS

MCP · A2A · OpenAPI — no protocol lock-in

MCP

Model Context Protocol — the open standard for exposing tools & context to any LLM client.

A2A

Agent-to-Agent — agents discover and call other agents, across vendors.

OpenAPI

Bring any existing REST API as a tool, straight from its spec.

Open protocols mean your tools and integrations aren't tied to one vendor's runtime.

Reuse what you already have (REST APIs, internal MCP servers) instead of rebuilding it.

Interoperability by design — a strict requirement for enterprise and public-sector buyers.

MEMORY

Built-in memory — no external database

Slide 23

MEMORY

Built-in memory — no external database

Short-term

The working context of the current conversation / thread — carried automatically.

Long-term

Facts and preferences that persist across sessions, per user or per agent.

Procedural

Learned how-to: reusable steps and workflows the agent should follow.

Managed by the service — you don't provision or operate a vector store or state DB.

Threads persist conversation state; memory makes agents feel continuous, not amnesiac.

Enterprise controls: scoping, retention and deletion respect your data governance.

IDENTITY

Entra Agent ID — every agent is a first-class identity

Slide 25

IDENTITY

Entra Agent ID — every agent is a first-class identity

Foundry auto-provisions an Entra identity for the agent across its lifecycle.

Three parts: blueprint (the app template) → instance (a deployment) → agent user (runtime identity in your org).

Least-privilege RBAC & Conditional Access — the agent only reaches what it's granted.

This is the bridge to the “Govern” plane: the same identity Agent 365 manages.

FOR GOVERNANCE & SECURITY

Agents stop being anonymous scripts. They get an auditable identity you manage like an employee's.

VOICE

Voice Live — real-time, speech-to-speech agents

Slide 26

VOICE

Voice Live — real-time, speech-to-speech agents

Natural, low-latency speech-to-speech: the agent listens and talks in real time.

Powered by Azure Speech inside Foundry Tools; connect by agent ID — logic stays in the agent.

The agent's prompt, tools and memory are reused; only the interaction channel changes.

Ideal for contact-centre, accessibility and hands-free enterprise scenarios.

WHY IT LANDS

Same agent, now a voice. It makes “an agent” tangible for a non-technical audience in seconds.
