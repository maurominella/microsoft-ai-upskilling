AGENT 365 · IDENTITY

Agent identity, blueprint, and the Autopilot identity

Slide 48

AGENT 365 · IDENTITY

Agent identity, blueprint, and the Autopilot identity

Three things people conflate — and only the last one is a real Microsoft 365 user.

SERVICE IDENTITY

Foundry Agent Identity

What you see in Foundry today

Auto-generated by Foundry

Authenticates the Hosted agent to Azure AI Agent Service

Runs tools, MCP and Work IQ in technical mode

Not an M365 user — no mailbox, Teams, calendar or Graph.

THE RECIPE

Agent Identity Blueprint

How the identity is defined

The template Foundry uses to mint agent identities

Sets attributes, grantable permissions and lifecycle

Governed by policy and Purview

Still not an M365 user.

REAL M365 IDENTITY

Autopilot Identity

The digital coworker — created at publish to Agent 365

Full M365 user: mailbox, calendar, Teams, OneDrive, SharePoint, Graph

Invited to meetings, emailed, @mentioned in Teams

RBAC + Conditional Access; managed like an employee

This is the identity Work IQ uses.

THE BOTTOM LINE

Your Foundry identity is a technical blueprint — not a Copilot, not a digital coworker, not an Autopilot. The real Microsoft 365 identity is created only when you publish the agent to Agent 365.

AGENT 365 · IDENTITY

Two identities by design — what Work IQ sees

Slide 49

AGENT 365 · IDENTITY

Two identities by design — what Work IQ sees

The identity your agent runs with decides what it is allowed to see.

WHAT WORK IQ SEES

✗ FOUNDRY IDENTITY ONLY

No meetings. The identity has no calendar, mailbox or Graph permissions.

✓ PUBLISHED TO AGENT 365

Work IQ sees the Autopilot’s meetings — it is a real M365 user.

WHY MICROSOFT SEPARATES THEM

Same split as a service principal (technical) versus a user identity (functional).

Keeping them apart prevents:

privilege escalation

accidental access to M365 data

Conditional Access bypass

incomplete audit and compliance gaps

THE MAPPING

Foundry Agent Identity → technical execution, Azure AI Agent Service only. Autopilot Identity → Microsoft 365 interaction: Graph, mailbox, calendar, Teams.
