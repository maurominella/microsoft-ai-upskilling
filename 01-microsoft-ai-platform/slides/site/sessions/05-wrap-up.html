TAKEAWAYS

What to remember — by role

For leadership (Group A)

Slide 53

TOMORROW

Day 2 — four hands-on labs (for the technical team)

Lab 1 · Create a prompt agent

Build an agent in the Foundry portal: model, instructions, playground.

Lab 2 · Add an MCP tool

Connect a tool via the Toolbox / MCP; invoke it from the agent.

Lab 3 · Call via Responses API

Use each agent's Coding panel: run it from code (Python / REST).

Lab 4 · Publish to Agent 365

Publish and invoke with the agent's own identity — without OBO.

45–60 minutes each · step-by-step scripts · follow along on your own machine
