The four technologies

Four pieces fit together: a framework to build with, a platform to run on, and two open protocols to connect everything.

AGENT FRAMEWORKThe open-source SDK for single agents and multi-agent workflows — .NET, Python and Go.
FOUNDRYThe managed platform that runs, scales, secures and observes agents in production.
MCPThe open standard connecting any agent to tools and data — the USB-C of AI.
A2AThe protocol for agents that discover, delegate to and collaborate with other agents.
