Five things to remember

1

An agent = model + instructions + tools, running in a loop

2

Agent Framework is HOW you build — open, multi-language

3

Foundry is WHERE it runs — managed, scaled, governed

4

MCP connects agents to tools & data — one open standard

5

A2A lets agents collaborate — open, and identity-aware
