MCP: security & governance

Authentication options

Key-based access

Microsoft Entra (agent / project managed identity)

OAuth On-Behalf-Of (identity passthrough)

Control what agents can do

Expose only a curated subset of tools

Least-privilege scopes per connection

Consent & approval before sensitive actions

Watch the trust boundary. A tool can return text that tries to hijack the agent — prompt injection, including cross-prompt injection (XPIA). Treat external MCP servers as untrusted: validate inputs/outputs, apply content safety, keep a human in the loop for high-impact actions, and know the spec keeps evolving on auth & security.

Slide text

Authentication options

Key-based access

  • Microsoft Entra (agent / project managed identity)
  • OAuth On-Behalf-Of (identity passthrough)

Watch the trust boundary. A tool can return text that tries to hijack the agent — prompt injection, including cross-prompt injection (XPIA). Treat external MCP servers as untrusted: validate inputs/outputs, apply content safety, keep a human in the loop for high-impact actions, and know the spec keeps evolving on auth & security.
