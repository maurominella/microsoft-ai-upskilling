Slide 12

THEME 1 · LANDSCAPE & VISION

Agentic AI on Microsoft Foundry · Day 1

11

The agentic loop

1. Perceive

Read the goal & context

2. Reason / plan

Decide the next step

3. Act

Call a tool or API

4. Observe

Read the result

Repeat until the goal is met. The loop is bounded by grounding (facts from your data), guardrails (safety & policy) and stopping conditions (max steps, cost, human approval).

Open by design: why protocols matter

Without standards

Every model × every tool = custom glue

M × N integrations to build and maintain

Fragile, duplicated, vendor-locked

New tool → rewrite for every agent

With open protocols

MCP + A2A turn M × N into M + N

Build a tool / agent once — reuse everywhere

Compose across vendors — no lock-in

Microsoft embraces the open ecosystem

Slide text

Without standards

  • Every model × every tool = custom glue
  • M × N integrations to build and maintain
  • Fragile, duplicated, vendor-locked
  • New tool → rewrite for every agent

With open protocols

  • MCP + A2A turn M × N into M + N
  • Build a tool / agent once — reuse everywhere
  • Compose across vendors — no lock-in
  • Microsoft embraces the open ecosystem
