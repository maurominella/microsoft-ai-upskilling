What is the A2A protocol?

An open protocol

Originated by Google, now under the Linux Foundation

Vendor-neutral standard for agent interop

Complements MCP — different job (see next)

Client agent ↔ remote agent

A client agent delegates a task

A remote agent performs and responds

Tasks & messages, with streaming updates

The Agent Card. Every A2A agent publishes a machine-readable card describing who it is, what skills it offers, its endpoint and how to authenticate — so other agents can discover it and know how to delegate. Discovery + capabilities + identity, in one document.

Consuming A2A agents — a loop of calls, or one workflow

Slide 46

Consuming A2A agents — a loop of calls, or one workflow

Plain A2A client

import asyncio

from a2a.client import create_client

from a2a.helpers import new_text_message

from a2a.types import Role, SendMessageRequest

 

CAMPAIGN_BRIEF = "sector=Travel; impressions=9200000"

async def main():

    client = await create_client("http://localhost:9999")

    async with client:

        request = SendMessageRequest(

            message=new_text_message(

                CAMPAIGN_BRIEF,

                role=Role.ROLE_USER,

            )

        )

        async for response in client.send_message(request):

            print(response.message.parts)

 

           

asyncio.run(main())

Microsoft Agent Framework client

import asyncio

from agent_framework.a2a import A2AAgent

 

 

CAMPAIGN_BRIEF = "sector=Travel; impressions=9200000"

async def main():

    pricing_agent = A2AAgent(

        name="PricingAgent",

        description="Computes an advertising campaign quote.",

        url="http://localhost:9999",

    )

    async with pricing_agent:

        result = await pricing_agent.run(CAMPAIGN_BRIEF)

    print(f"Pricing: {result.text}")

 

 

asyncio.run(main())
